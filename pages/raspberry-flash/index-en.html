Raspberry Flash

Version 1.1 · Windows 10/11 · needs administrator rights

Writes Raspberry Pi images to SD cards. Enter your server once and every card gets the version that is current right now.

  • Reads manifest.json and downloads a new image only when it changes
  • Resumes interrupted downloads where they stopped
  • Reads every card back and checks it against the image
  • Handles .img, .img.xz, .img.gz, .img.bz2 and .zip
  • Lists only USB and SD card readers, never your system disk

Manifest Maker

Version 1.0 · Windows 10/11 · no administrator rights

Creates the manifest.json that tells Raspberry Flash which image is current. Pick the image, save, upload.

How it works

Publish once, flash everywhere

Your images live on any web server. A small manifest next to them says which one is current.

1

Upload the image

Put the new .img on your server, with a new file name for each version.

2

Create the manifest

Run Manifest Maker on the same image and upload the manifest.json it saves.

3

Flash

Raspberry Flash sees the new version, downloads it once and writes every card from then on.

The server folder holds the images and one manifest:

manifest.jsonJSON
{
  "version": "231026",
  "image": "solaria231026.img",
  "sha256": "3f5a…"
}

image is the file name in the same folder (or a full link). sha256 is optional: when present, the image is checked after downloading.

Step by step

Flashing an SD card

  1. Insert the SD card and start RaspberryFlash.exe. Accept the administrator request.
  2. In Base URL, enter the folder that holds your images, e.g. https://your-server.com/images/. Press Save to keep it in the list.
  3. Select the card in SD card. Press Refresh if it is not listed.
  4. Press Flash and confirm. Everything on the selected card is erased.
  5. Wait for “SD card written successfully”, then remove the card.
Good to know Downloaded images are kept in the cache folder next to the program, so the next card is written straight away. Delete old images there to free disk space.

Publishing a new image

  1. Upload the new image to the server folder with a new file name, e.g. solaria151126.img.
  2. Start ManifestMaker.exe and press Browse… to select the same image on your PC.
  3. Check the Version and keep Include SHA-256 checksum ticked.
  4. Press Create manifest, then upload manifest.json to the server folder, replacing the old one.
FAQ

Questions

Is it really free?

Yes. Raspberry Flash and Manifest Maker are free to download and use, with no account or licence key.

Windows says “Windows protected your PC”. Is that normal?

Windows SmartScreen shows this for programs it has not seen often. Click More info, then Run anyway. Download the files only from this page.

Why does Raspberry Flash need administrator rights?

Writing an image means writing the SD card directly, which Windows only allows to administrators. Manifest Maker does not need them.

Can I use a direct link instead of a manifest?

Yes. A link that ends in .img, .img.xz, .img.gz, .img.bz2 or .zip is downloaded and written directly, without a manifest.

Why did it not download my new image?

Raspberry Flash recognises an image by its file name. If the new image has the same name as one already in the cache, the cached copy is used. Give each version a new name and update the manifest.

Verification failed. What now?

Flash the card again. If it fails repeatedly, the card or the reader is likely faulty: try another card.
