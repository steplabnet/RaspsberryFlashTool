Come funziona

Pubblichi una volta, scrivi ovunque

Le immagini stanno su un qualsiasi server web. Un piccolo manifest accanto a loro indica qual è quella attuale.

1

Carica l'immagine

Metti il nuovo .img sul server, con un nome di file diverso per ogni versione.

2

Crea il manifest

Apri la stessa immagine con Manifest Maker e carica il manifest.json che salva.

3

Scrivi

Raspberry Flash vede la nuova versione, la scarica una volta e da lì in poi la scrive su ogni scheda.

La cartella sul server contiene le immagini e un manifest:

manifest.jsonJSON
{
  "version": "231026",
  "image": "solaria231026.img",
  "sha256": "3f5a…"
}

image è il nome del file nella stessa cartella (o un link completo). sha256 è facoltativo: se presente, l'immagine viene controllata dopo il download.

Passo per passo

Scrivere una scheda SD

  1. Inserisci la scheda SD e avvia RaspberryFlash.exe. Accetta la richiesta di amministratore.
  2. In Base URL inserisci la cartella che contiene le immagini, ad es. https://your-server.com/images/. Premi Save per tenerla nell'elenco.
  3. Seleziona la scheda in SD card. Premi Refresh se non compare.
  4. Premi Flash e conferma. Tutto il contenuto della scheda selezionata viene cancellato.
  5. Attendi il messaggio “SD card written successfully”, poi rimuovi la scheda.
Da sapere Le immagini scaricate restano nella cartella cache accanto al programma, così la scheda successiva viene scritta subito. Cancella lì le immagini vecchie per liberare spazio.

Pubblicare una nuova immagine

  1. Carica la nuova immagine nella cartella del server con un nuovo nome di file, ad es. solaria151126.img.
  2. Avvia ManifestMaker.exe e premi Browse… per selezionare la stessa immagine sul tuo PC.
  3. Controlla la Version e lascia spuntato Include SHA-256 checksum.
  4. Premi Create manifest, poi carica manifest.json nella cartella del server, sostituendo quello vecchio.
FAQ

Domande frequenti

È davvero gratuito?

Sì. Raspberry Flash e Manifest Maker sono gratuiti da scaricare e usare, senza account né chiave di licenza.

Windows mostra “PC protetto da Windows”. È normale?

Windows SmartScreen lo mostra per i programmi che vede raramente. Fai clic su Ulteriori informazioni, poi su Esegui comunque. Scarica i file solo da questa pagina.

Perché Raspberry Flash richiede i diritti di amministratore?

Scrivere un'immagine significa scrivere direttamente la scheda SD, cosa che Windows consente solo agli amministratori. Manifest Maker non ne ha bisogno.

Posso usare un link diretto invece di un manifest?

Sì. Un link che termina con .img, .img.xz, .img.gz, .img.bz2 o .zip viene scaricato e scritto direttamente, senza manifest.

Perché non ha scaricato la mia nuova immagine?

Raspberry Flash riconosce un'immagine dal nome del file. Se la nuova immagine ha lo stesso nome di una già presente nella cache, usa la copia in cache. Dai a ogni versione un nome nuovo e aggiorna il manifest.

La verifica non è riuscita. Cosa faccio?

Scrivi di nuovo la scheda. Se fallisce più volte, probabilmente la scheda o il lettore sono difettosi: prova con un'altra scheda.
