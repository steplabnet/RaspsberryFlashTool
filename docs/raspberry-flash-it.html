Raspberry Flash – Guida utente

Scrivere schede SD per Raspberry Pi da Windows · RaspberryFlash 1.1

Raspberry Flash scrive un'immagine Raspberry Pi su una scheda SD da Windows. Usa sempre l'ultima immagine pubblicata sul vostro server web, quindi basta conoscere l'indirizzo del server: quando viene pubblicata una nuova immagine, questa viene usata automaticamente.

L'interfaccia del programma è in inglese. In questa guida i nomi di pulsanti e campi sono riportati come appaiono sullo schermo, in grassetto.

1. Requisiti

  • Windows 10 o Windows 11.
  • Un lettore di schede SD (integrato o USB) e una scheda SD grande almeno quanto l'immagine.
  • Una connessione internet la prima volta che si scarica ogni nuova immagine.
  • Diritti di amministratore: scrivere una scheda significa accedere direttamente al disco, cosa che Windows consente solo agli amministratori. All'avvio Windows chiede l'autorizzazione (finestra UAC): rispondete Sì.

Non serve installare nulla: copiate RaspberryFlash.exe in una cartella a scelta e avviatelo. Scegliete una cartella in cui sia possibile scrivere (ad es. Documenti\RaspberryFlash), perché il programma salva accanto a sé le impostazioni e le immagini scaricate.

2. Come funziona

L'indirizzo del server che inserite (il base URL) è una cartella che contiene l'immagine e un piccolo file chiamato manifest.json che indica qual è l'immagine corrente. Quando premete Flash, Raspberry Flash:

  1. legge manifest.json dall'indirizzo base;
  2. controlla se l'immagine indicata è già presente nella cartella locale cache;
  3. se non c'è, la scarica (riprendendo un eventuale download interrotto);
  4. cancella la scheda SD selezionata e vi scrive l'immagine;
  5. se richiesto, rilegge la scheda per verificarla.

3. Scrivere una scheda SD

La finestra principale contiene, dall'alto in basso:

  • Base URL – indirizzo del server, con i pulsanti Save (salva) e Remove (rimuovi)
  • SD card – la scheda da scrivere, con il pulsante Refresh (aggiorna)
  • le opzioni Verify after writing e Show all non-system disks
  • due barre di avanzamento, Download e Write (scrittura)
  • una riga di stato e un registro (log) delle operazioni
  • i pulsanti About, Flash e Cancel (annulla)

Passo per passo

  1. Inserite la scheda SD nel lettore.
  2. Avviate RaspberryFlash.exe e confermate la richiesta di Windows per i diritti di amministratore.
  3. Inserite il Base URL – la cartella del server che contiene manifest.json, ad esempio https://drive.example.com/.
    Premete Save per aggiungerlo all'elenco a discesa e ritrovarlo la volta successiva. Con Remove eliminate dall'elenco l'indirizzo selezionato.
  4. Selezionate la scheda in SD card. Ogni voce mostra numero del disco, nome, capacità e tipo di collegamento, ad es. Disk 3: Generic STORAGE DEVICE [29.7 GB, USB]. Se la scheda non compare, premete Refresh.

    Controllate la capacità: deve corrispondere alla vostra scheda SD. In caso di dubbio, togliete la scheda, premete Refresh e guardate quale voce scompare.

  5. Premete Flash. Un avviso indica quale disco sta per essere cancellato. Leggetelo con attenzione e premete Sì per continuare.

    Tutto il contenuto della scheda selezionata viene cancellato. L'operazione non si può annullare.

  6. Attendete. La barra Download si riempie durante lo scaricamento dell'immagine (appare subito piena se l'immagine è già nella cache). La barra Write mostra poi la scrittura e, se attiva, la verifica. Velocità e avanzamento compaiono anche nella riga di stato.
  7. Quando compare il messaggio “SD card written successfully. You can remove it.” (scheda scritta correttamente, potete toglierla), premete OK ed estraete la scheda. È pronta per il Raspberry Pi.

Per interrompere in qualsiasi momento premete Cancel. Un download annullato riprende la volta successiva; una scrittura annullata lascia la scheda inutilizzabile finché non viene riscritta.

Dopo la scrittura Windows potrebbe mostrare “È necessario formattare il disco prima di poterlo usare”. È normale: il Raspberry Pi usa partizioni che Windows non sa leggere. Premete Annulla – non formattate.

Scrivere più schede

Inserite la scheda successiva, premete Refresh, selezionatela e premete Flash. L'immagine viene scaricata una sola volta e poi riutilizzata dalla cache.

4. Opzioni

Verify after writing – verifica dopo la scrittura (attiva di default, consigliata)
Dopo la scrittura il programma rilegge l'intera scheda e la confronta con l'immagine. Il tempo totale circa raddoppia, ma si individuano schede difettose o contraffatte prima di montarle in un dispositivo. L'impostazione viene ricordata.
Show all non-system disks – mostra tutti i dischi non di sistema
Normalmente vengono elencati solo i dischi USB, SD e MMC. Attivatela se il vostro lettore non viene riconosciuto come tale (alcuni lettori integrati). Il disco di sistema di Windows non viene mai elencato, ma altri dischi interni o esterni sì: assicuratevi di selezionare quello giusto.
Link diretto all'immagine
Al posto dell'indirizzo base si può inserire il link diretto a un file immagine che termina con .img, .img.xz, .img.gz, .img.bz2 o .zip. Le immagini compresse vengono decompresse durante la scrittura; non serve estrarle prima.

Mostra la revisione del programma e i contatti.

Il registro nella finestra principale mostra ogni passaggio con l'orario: è utile copiarlo quando si chiede assistenza.

7. Domande frequenti

È gratuito?
Sì, Raspberry Flash è gratuito da scaricare e usare.
Come so quale versione sto scrivendo?
Ogni volta che premete Flash, il registro mostra Available version: … con il nome dell'immagine.
Posso usarlo senza connessione?
Per leggere manifest.json serve la connessione. Senza, inserite invece il link diretto all'immagine: se un file con quel nome è già nella cache, viene usato senza scaricare nulla.
Dopo la scrittura la scheda sembra più piccola?
Windows vede solo la piccola partizione di avvio, quindi la scheda sembra più piccola. La capacità completa c'è ancora ed è usata dal Raspberry Pi.
Come vengono pubblicate le nuove immagini?
