Raspberry Flash – User Guide

Writing Raspberry Pi SD cards on Windows · RaspberryFlash 1.1

Raspberry Flash writes a Raspberry Pi image to an SD card on Windows. It always takes the latest image published on your web server, so you only need to know the server address: when a new image is published, it is picked up automatically.

1. Requirements

  • Windows 10 or Windows 11.
  • An SD card reader (built-in or USB) and an SD card at least as large as the image.
  • An internet connection the first time each new image is downloaded.
  • Administrator rights: writing a card bypasses the file system, which Windows only allows to administrators. When you start the program, Windows asks for permission (UAC prompt) – answer Yes.

No installation is needed: copy RaspberryFlash.exe to a folder of your choice and run it. Pick a folder where you can write files (e.g. Documents\RaspberryFlash), because the program stores its settings and downloaded images next to itself.

2. How it works

The server address you enter (the base URL) is a folder holding the image and a small file named manifest.json that says which image is current. When you press Flash, Raspberry Flash:

  1. reads manifest.json from the base URL;
  2. checks whether the image named there is already in its local cache folder;
  3. downloads it if it is not (resuming any interrupted download);
  4. erases the selected SD card and writes the image to it;
  5. optionally reads the card back to verify it.

3. Writing an SD card

The main window contains, from top to bottom:

  • Base URL – server address, with Save and Remove buttons
  • SD card – the card to write, with a Refresh button
  • the Verify after writing and Show all non-system disks options
  • two progress bars, Download and Write
  • a status line and a log of what the program is doing
  • the About, Flash and Cancel buttons

Step by step

  1. Insert the SD card into the reader.
  2. Start RaspberryFlash.exe and accept the Windows administrator prompt.
  3. Enter the Base URL – the server folder that contains manifest.json, for example https://drive.example.com/.
    Press Save to add it to the drop-down list so you can pick it next time. Use Remove to delete the selected address from the list.
  4. Select the card in SD card. Each entry shows disk number, name, size and connection type, e.g. Disk 3: Generic STORAGE DEVICE [29.7 GB, USB]. If the card is not listed, press Refresh.

    Check the size: it must match your SD card. If in doubt, remove the card, press Refresh, and see which entry disappears.

  5. Press Flash. A warning shows which disk is going to be erased. Read it carefully and press Yes to continue.

    Everything on the selected card is erased. This cannot be undone.

  6. Wait. The Download bar fills while the image is downloaded (it shows full immediately if the image is already in the cache). The Write bar then shows writing and, if enabled, verifying. Speed and progress also appear in the status line.
  7. When the message “SD card written successfully. You can remove it.” appears, press OK and remove the card. It is ready to go into the Raspberry Pi.

To stop at any moment, press Cancel. A cancelled download resumes next time; a cancelled write leaves the card unusable until it is written again.

After writing, Windows may show “You need to format the disk before you can use it”. This is normal: Raspberry Pi uses partitions Windows cannot read. Press Cancel – do not format.

Writing several cards

Insert the next card, press Refresh, select it and press Flash. The image is downloaded only once and then reused from the cache.

4. Options

Verify after writing (on by default, recommended)
After writing, the program reads the whole card back and compares it with the image. It roughly doubles the time but detects faulty or counterfeit cards before they go into a device. The setting is remembered.
Show all non-system disks
Normally only USB, SD and MMC disks are listed. Tick this if your reader is not detected as such (some internal readers). The Windows system disk is never listed, but other internal or external hard disks may be – make sure you select the right one.
Direct image link
Instead of a base URL you can enter a direct link to an image file ending in .img, .img.xz, .img.gz, .img.bz2 or .zip. Compressed images are decompressed while writing; there is no need to unpack them first.
About
Shows the program revision and contact details.

5. Files next to the program

File / folderContents
cache\Downloaded images. Delete old images to free space; they are downloaded again if needed.
cache\*.part, *.part.jsonAn unfinished download. Pressing Flash resumes it.
config.jsonSettings: last URL, saved URLs, verify option. Delete it to reset the program.

6. Troubleshooting

Message / problemCause and solution
Administrator rights are required to write to the SD card.The Windows prompt was refused. Restart the program and answer Yes; on company PCs you may need an administrator account.
No SD card found. Insert one and press Refresh.Insert the card, wait a few seconds, press Refresh. If the reader is internal, try Show all non-system disks.
Please enter a valid http(s) URL.The address must start with http:// or https://.
Cannot read manifest.json: HTTP 404 …Wrong base URL, or the image has not been published there yet. Check the address with whoever publishes the images.
Cannot read manifest.json: … (no HTTP code)No connection to the server: check the internet connection, proxy or firewall.
manifest.json is not valid JSON / has no "image" entry / Download failed: HTTP 404 …A problem on the server side. Tell whoever publishes the images.
Connection problem …; retrying in 5sTemporary network fault; the program retries by itself. If it gives up, press Flash again: the download resumes where it stopped.
Downloaded image is corrupted (checksum mismatch).The download was damaged and has been deleted; press Flash to download again. If it happens every time, tell whoever publishes the images.
Image (…) is larger than the card (…)Use a larger SD card.
diskpart failedThe card is write-protected (check the small lock switch on the side of the card or adapter), or another program is using it. Close Explorer windows on the card and try again.
Verification failed …The card did not store the data correctly. Try again; if it fails again, the card or the reader is faulty – replace it.
An old image is still being writtenDelete the old image from the cache folder and press Flash again.
Windows asks to format the card after writingNormal – press Cancel, do not format.

The log in the main window shows every step with the time; it is useful to copy it when asking for help.

7. FAQ

Is it free?
Yes, Raspberry Flash is free to download and use.
How do I know which version I am writing?
The log shows Available version: … with the image name each time you press Flash.
Can I use it offline?
Reading manifest.json needs a connection. Without one, enter a direct link to the image instead: if a file with that name is already in the cache, it is used without downloading.
Does the card shrink after writing?
Windows only sees the small boot partition, so the card looks smaller. The full capacity is still there and is used by the Raspberry Pi.
How are new images published?
With Manifest Maker – see the Manifest Maker guide.
